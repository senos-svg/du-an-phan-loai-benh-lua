# Rice Leaf Disease Classification

A Streamlit web application for classifying rice-leaf images with two trained models:

- YOLO11n-cls
- ResNet18

The app supports single-model inference or side-by-side comparison. It displays the predicted class and the six class scores.

> This is an educational image-classification prototype. It is not an agricultural diagnosis tool. A confidence score is not a guarantee that a prediction is correct. The current six-class classifier does not reliably detect images outside its training distribution.

## 2. Required model files

The supplied `nhom3.zip` contains notebooks, a PDF report, and a PowerPoint presentation, but **does not contain the trained `.pt` or `.pth` checkpoint files**.

Before running the app, copy the exact trained checkpoints into `models/`:

```text
models/best.pt
models/resnet18_best.pth
```

The training/deployment notebook refers to these original locations:

- YOLO: `runs/Rice_Disease_YOLO11_Aug/weights/best.pt`
- ResNet18: `results_resnet18/resnet18_best.pth`

Use the checkpoint generated by the final experiment, not `last.pt` unless that is intentionally the selected checkpoint. The YOLO file must be a classification checkpoint (`task=classify`).

Model files are tracked with Git LFS through `.gitattributes`. Streamlit Community Cloud supports repositories that use Git LFS. Install Git LFS before committing the checkpoints:

```bash
git lfs install
```

Do not upload the full image dataset to this repository unless you have verified its license and have a clear reason to redistribute it. The application only needs the two model checkpoints.

## 3. Run locally

Recommended: Python 3.12 or a Python version supported by the installed PyTorch and Ultralytics releases.

### Windows PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Open the local URL printed by Streamlit (normally `http://localhost:8501`).

## 4. Publish the source to GitHub

Create an empty repository on GitHub, for example `rice-leaf-disease-classifier`. Then run these commands from this project folder:

```bash
git init
git lfs install
git add .
git commit -m "Initial rice leaf disease classifier"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/rice-leaf-disease-classifier.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username. If the repository already exists locally, do not run `git init` again; configure the remote and push the existing branch.

## 5. Deploy the web app with Streamlit Community Cloud

GitHub stores the source code; it does not run this Python/PyTorch inference app by itself. The suggested deployment path is Streamlit Community Cloud connected to the GitHub repository.

1. Push the project to GitHub.
2. Sign in to Streamlit Community Cloud with GitHub.
3. Choose **Create app**.
4. Select the repository, branch `main`, and entrypoint `app.py`.
5. Select a supported Python version in Advanced settings if needed.
6. Deploy and inspect the app logs if dependency installation or model loading fails.

Official guide: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app

The app requires the two checkpoints at deployment time. If you keep model files outside GitHub, update the application to download them from a trusted model-storage location, or use a private model repository with suitable access controls. Never put access tokens in source code.

## 6. Preprocessing and class order

The ResNet inference transform matches the training notebook:

- Resize to `224 x 224`.
- Convert to tensor.
- Normalize with ImageNet mean `[0.485, 0.456, 0.406]` and std `[0.229, 0.224, 0.225]`.

Class order:

1. Blast
2. Brown spot
3. Healthy
4. Leaf smut
5. Rice Tungro
6. Sheath blight

YOLO output classes are mapped by class name, not assumed index order.

## 7. Important limitations to disclose

- The supplied ZIP does not include the final checkpoints, so the web app cannot run inference until they are added.
- The supplied notebook paths are specific to Kaggle and Google Drive; the Streamlit app uses paths relative to the repository.
- The data-preparation notebook reports 16 exact-duplicate files and 47 near-duplicate cross-class pairs. These need manual label review and group-aware splitting to reduce leakage risk.
- The notebook's confidence / margin / entropy thresholds are starting values, not validated OOD thresholds. The app therefore displays confidence as a model score and does not claim that it can reliably reject all non-rice images.
- The reported latency values were measured with different inference pipelines. Benchmark again with identical hardware, batch size, warm-up, preprocessing, and CUDA synchronization before making a speed claim.
- The app is a six-class classifier. It does not draw bounding boxes or segment disease regions.
